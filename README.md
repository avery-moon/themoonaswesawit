# The Moon As We Saw It — v0.2

Single-page interactive exhibit for GitHub Pages. Upload the **contents** of this directory to the root of the `themoonaswesawit` repository. No build step required.

## Features
- Centered NASA near-side Moon reference, 16 orbital markers, chronology slider and keyboard arrows.
- Context-rich labels, institution links, compact source and method dialogs.
- Historical objects shown separately unless image alignment can be substantiated.

## Image status
The central image uses the NASA Artemis II near-side photograph `art002e009057`, hosted remotely by NASA. It is a real image, not a schematic. If the external host blocks embedding or changes the URL, use a locally downloaded NASA original at `assets/moon-nasa.jpg` and update `index.html`. The artifact thumbnails are *candidates*; not all have confirmed image URLs, and the site intentionally links to source pages rather than fabricate pictures.

The comparison control remains disabled where an authentic, alignable historic image has not been verified. A working drag comparison will require verified imagery and appropriate alignment.
